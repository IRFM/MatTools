The MatTools folder contains dedicated Matlab functions for LUKE that be used for other purposes.

There are also several external functions that can be downloaded from website or git repositories :

******************************************************************

cprintf : color text in command window (cprintf_114.m for matlab < 2025, cprint_p for matlab >= 2025)

https://fr.mathworks.com/matlabcentral/fileexchange/24093-cprintf-display-formatted-colored-text-in-command-window

******************************************************************

DataHash : Checksum for Matlab array of any type

https://fr.mathworks.com/matlabcentral/fileexchange?c%5B%5D=fileexchange&q=DataHash

******************************************************************

hypergeometric2f1 : Computes a hypergeometric function using the series expansion

https://fr.mathworks.com/matlabcentral/fileexchange/1844-gaussian-hypergeometric-function?s_tid=srchtitle

******************************************************************

shadedplot : Plot two lines, then shade the area between those two lines.

https://fr.mathworks.com/matlabcentral/fileexchange/18738-shaded-area-plot?s_tid=srchtitle

******************************************************************

vsize : VSIZE determines the full anatomy for named or unnamed variables of any depth and complexity

https://fr.mathworks.com/matlabcentral/fileexchange/12278-vsize-a-pedestrian-variable-decoder?s_tid=srchtitle

******************************************************************

findjobj : Find java objects contained within a specified java container or Matlab GUI handle

https://fr.mathworks.com/matlabcentral/fileexchange/14317-findjobj-find-java-handles-of-matlab-graphic-objects?s_tid=srchtitle

******************************************************************
